# Image Production Plan

## Principle
Use generated imagery for brand, mood, category, and campaign assets. Use real or official imagery for actual products, the physical store, staff, and events whenever possible.

## Image generation style rules
Generated assets should share a common system:
- Dark, mature, collector-oriented
- Vintage comic print influence
- Subtle goth / horror-comic personality
- Halftone and print texture used selectively
- Avoid copyrighted character likenesses as the core of original brand graphics
- Avoid childish superhero parody aesthetics
- Leave usable negative space for Wix copy and CTAs where needed
- Product-like objects shown in brand art should be generic, not misleading representations of inventory

## Real-image sourcing rules
Prefer:
- Original store photography
- Official publisher/manufacturer/distributor media assets
- Assets provided through legitimate product feeds
- Licensed stock only where necessary

Avoid using random search-engine images without confirmed rights.
